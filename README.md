# fy2ne Articles & Research Repository

Canonical source of research papers, protocol specifications, post-mortems, and technical essays published on [fy2ne.me/articles](https://fy2ne.me/articles).

Each folder contains:
- `README.md`: The article's raw markdown content.
- `config.json`: Author metadata, publication tags, and reading specs.
- `banner.png`: Canonical cover banner graphic.
